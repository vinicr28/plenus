SECTION 2: PARALLAX SCROLL EFFECT WITH PLANTS
--------------------------------------------------------------------------------

CONCEPT:
Add decorative plant/leaf PNG images that move at different speeds during scroll,
creating depth and a natural, organic feel that complements the home construction theme.

STEP 1: Create Plant Assets
- Create or source 4-6 PNG images of plants/leaves with transparent backgrounds
- Suggested elements: monstera leaves, ferns, eucalyptus branches, palm fronds
- Place in: /public/decorative/plant-1.png, plant-2.png, etc.
- Recommended sizes: 200-400px width, optimized for web

STEP 2: Create ParallaxPlants Component

File: /src/components/ParallaxPlants.tsx

```tsx
"use client";

import { useScroll, useTransform, motion } from "framer-motion";
import { useRef } from "react";

interface PlantLayer {
  src: string;
  position: { top?: string; bottom?: string; left?: string; right?: string };
  speed: number; // negative = moves up, positive = moves down
  scale?: number;
  rotation?: number;
  opacity?: number;
}

const plants: PlantLayer[] = [
  {
    src: "/decorative/plant-1.png",
    position: { top: "10%", left: "-5%" },
    speed: -100,
    scale: 1.2,
    rotation: -15,
    opacity: 0.7,
  },
  {
    src: "/decorative/plant-2.png",
    position: { top: "30%", right: "-8%" },
    speed: -150,
    scale: 1,
    rotation: 10,
    opacity: 0.6,
  },
  {
    src: "/decorative/plant-3.png",
    position: { bottom: "20%", left: "-3%" },
    speed: -80,
    scale: 0.8,
    rotation: 5,
    opacity: 0.5,
  },
  {
    src: "/decorative/plant-4.png",
    position: { bottom: "10%", right: "-6%" },
    speed: -120,
    scale: 1.1,
    rotation: -8,
    opacity: 0.65,
  },
];

export default function ParallaxPlants() {
  const ref = useRef(null);
  const { scrollYProgress } = useScroll({
    target: ref,
    offset: ["start start", "end start"],
  });

  return (
    <div ref={ref} className="fixed inset-0 pointer-events-none z-0 overflow-hidden">
      {plants.map((plant, index) => {
        const y = useTransform(scrollYProgress, [0, 1], [0, plant.speed]);

        return (
          <motion.img
            key={index}
            src={plant.src}
            alt=""
            style={{
              y,
              ...plant.position,
              scale: plant.scale || 1,
              rotate: plant.rotation || 0,
              opacity: plant.opacity || 0.5,
            }}
            className="absolute w-auto h-auto max-w-[300px]"
          />
        );
      })}
    </div>
  );
}
```

STEP 3: Alternative Pure CSS Approach (Better Performance)

Add to globals.css:

```css
@supports (animation-timeline: scroll()) {
  .parallax-plant {
    animation: parallax-move linear;
    animation-timeline: scroll(root);
  }

  .parallax-plant-slow {
    animation-range: 0% 100%;
  }

  .parallax-plant-medium {
    animation-range: 0% 150%;
  }

  .parallax-plant-fast {
    animation-range: 0% 200%;
  }

  @keyframes parallax-move {
    from { transform: translateY(0); }
    to { transform: translateY(-200px); }
  }
}

/* Respect user preferences */
@media (prefers-reduced-motion: reduce) {
  .parallax-plant {
    animation: none;
  }
}
```

SECTION 3: LIQUID GLASS EFFECT FOR ALL BOXES

STEP 1: Create Reusable Glass Card Component

File: /src/components/GlassCard.tsx

```tsx
interface GlassCardProps {
  children: React.ReactNode;
  className?: string;
  intensity?: "light" | "medium" | "strong";
}

const intensityStyles = {
  light: {
    background: "linear-gradient(135deg, rgba(255,255,255,0.1) 0%, rgba(255,255,255,0.05) 100%)",
    border: "1px solid rgba(255,255,255,0.15)",
    blur: "backdrop-blur-md",
  },
  medium: {
    background: "linear-gradient(135deg, rgba(255,255,255,0.2) 0%, rgba(255,255,255,0.1) 100%)",
    border: "1px solid rgba(255,255,255,0.25)",
    blur: "backdrop-blur-xl",
  },
  strong: {
    background: "linear-gradient(135deg, rgba(255,255,255,0.25) 0%, rgba(255,255,255,0.1) 50%, rgba(255,255,255,0.05) 100%)",
    border: "1px solid rgba(255,255,255,0.3)",
    blur: "backdrop-blur-2xl",
  },
};

export default function GlassCard({
  children,
  className = "",
  intensity = "medium"
}: GlassCardProps) {
  const styles = intensityStyles[intensity];

  return (
    <div
      className={`rounded-2xl p-6 ${styles.blur} ${className}`}
      style={{
        background: styles.background,
        border: styles.border,
        boxShadow: "0 8px 32px rgba(0,0,0,0.2), inset 0 1px 0 rgba(255,255,255,0.2), inset 0 -1px 0 rgba(0,0,0,0.1)",
      }}
    >
      {children}
    </div>
  );
}
```

--------------------------------------------------------------------------------
SECTION 7: PERFORMANCE CONSIDERATIONS
--------------------------------------------------------------------------------

- Use will-change: transform on parallax elements
- Implement lazy loading for plant images
- Consider using CSS scroll-driven animations for better performance
- Test backdrop-filter performance on mobile devices
- Use transform: translateZ(0) to trigger GPU acceleration
- Limit parallax elements to 4-6 for optimal performance

--------------------------------------------------------------------------------
SECTION 8: BROWSER SUPPORT
--------------------------------------------------------------------------------

- backdrop-filter: Supported in all modern browsers (Chrome 76+, Firefox 103+, Safari 9+)
- CSS scroll-driven animations: Chrome 115+, Edge 115+ (use JavaScript fallback)
- Provide fallback solid backgrounds for older browsers
